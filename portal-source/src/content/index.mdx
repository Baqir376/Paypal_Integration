Salix listens to recorded sales calls in English, Urdu and Roman Urdu. It scores each deal, writes a coaching plan for the weakest skills, and tests salespeople against a buyer built from the deals they lost.

## Try it

```python
from salix_api import SalixApiClient

client = SalixApiClient(base_url="http://localhost:8000")
client.auth_api.post_auth_login(body={"email": "you@company.com", "password": "your password"})

print(client.billing.get_billing().balance)
```

The client keeps your session after you log in, so later calls are signed in.
